# データソース調査

## 1. 調査範囲と読み方

本書は JRA 中央競馬を対象とする研究用データ源を、取得可能な情報、履歴範囲、更新時点、取得方式、料金、利用条件の観点から比較する。調査日は **2026-08-30** である。

以下では、公式文書に直接書かれている内容を「事実」、そこから本プロジェクトについて導く判断を「解釈・示唆」、公式確認を得られていない事項を「不確実性」として分ける。「Web 画面で閲覧できる」ことは、「自動取得、恒久保存、加工、機械学習利用、再配布の許諾」があることを意味しない。

### 調査した質問

- 各候補から、レース、結果、馬、騎手、調教師、血統、調教、馬体重、天候・馬場、ラップ、オッズ、払戻の何を取得できるか。
- 履歴開始時期、欠損、更新頻度、訂正、当時スナップショット、オッズ時系列の保証は何か。
- API、公式ソフト、ファイル、Web のどの経路で取得し、認証、対応 OS、頻度・処理量の制約は何か。
- 料金はいくらか。自動取得、保存、加工、個人 ML、共同利用、再配布、商用利用のどこまで公式に確認できるか。
- 本プロジェクトの個人研究 MVP で現実的な主ソースと補助ソースは何か。

## 2. 結論要約

### 事実

- JRA-VAN Data Lab. は、公式 JV-Link インターフェースで取得するプログラム向けサービスであり、1986 年以降を中心とする JRA データ、レース前変更、馬体重、オッズ、調教等を提供する。通常料金は月額 2,090 円（税込）、初回 1 か月無料である。
- JRA-VAN の公式サポートは 2026-08-07、個人のローカル研究で、正規の JV-Link を使い、生データを外部 AI に送らないという質問条件について、利用規約上問題ないと回答している。一方、通常契約データを使った第三者向けサービスや商用再提供は認められず、別途 JRADB の法人契約が必要である。
- JV-Link は Windows 10/11 日本語版で動作する ActiveX/COM コンポーネントであり、取得データをローカルに蓄積してアプリケーションから参照する設計である。
- JRA 公式 Web、netkeiba、JBIS には有用な閲覧情報があるが、今回確認した公式資料には、本プロジェクトが必要とする一括・継続自動取得 API と、その保存・ML 利用を包括的に許諾する記載がない。
- JRDB は機械処理しやすい定型ファイルと独自指数・調教・パドック情報を提供するが、会員規約は個人の競馬予想用途に限定し、第三者提供・商用利用等を制約している。ML 学習、チーム共有、学習済みモデルの配布について明示的な許諾は確認できなかった。

### 解釈・示唆

- MVP の主データ源として、取得方法と個人研究利用の根拠が最も明確なのは JRA-VAN Data Lab./JV-Link である。
- JRA 公式 Web は照合・目視確認に使い、スクレイピングを前提にしない。netkeiba と JBIS も、書面による許諾または公式 API 契約が得られるまでは大量取得源にしない。
- 法人化、共同利用、外部クラウドへの生データ保存、第三者向け画面、予測の有償提供を行う時点で、現在の個人契約の範囲を超える可能性が高い。実装前ではなく、用途変更前に JRA-VAN/JRADB へ書面確認する。
- JRA-VAN の履歴取得だけでは「当時見えていた版」を完全再現できない。将来の厳密な検証のため、正規取得データを受信時刻付きでローカルに版管理する必要がある。

## 4. JRA-VAN Data Lab./JV-Link

### 4.1 提供内容と履歴

#### 事実

JVData 仕様書のセットアップデータ一覧から、少なくとも次を確認できる。

- レース詳細、馬ごとの競走馬情報、払戻、主要投票数、競走馬・馬主・生産者等の基本情報は原則 1986 年から。
- 単勝・複勝・枠連・馬連の最終オッズは 1993-06 から。ワイドは 1999-10、馬単・三連複は 2002-06、三連単は 2004-08 から。
- 木曜出馬表発表時点の競走馬・騎手・調教師・馬主・生産者情報スナップショットは 2004 年から。
- 坂路調教は 2003 年から。ウッドチップ調教は美浦 2021-07-27、栗東 2021-12-07 から。
- セリ取引価格は 1997 年から。
- JRA に関係する地方・海外成績は原則 2000 年からで、地方/海外競馬全体を網羅するものではない。
- 1994-07 より前の一部項目は未整備である。JRA-VAN は元データの誤りを独自判断で訂正せず、元データの訂正後に更新データが提供される場合がある。

主なレコードは以下である。

- レース（RA）：開催、競馬場、競走番号、発走時刻、距離、芝/ダート、コース、条件、クラス/グレード、天候、馬場状態、頭数、ラップ、コーナー通過等。
- 馬毎レース情報（SE）：馬、性齢、調教師、馬主、枠/馬番、斤量、騎手・変更、馬体重、着順、走破時計、着差、通過順位、上がり、賞金、確定単勝オッズ・人気等。
- 速報系：馬体重（WH）、天候馬場状態変更（WE）、出走取消・競走除外（AV）、騎手変更（JC）、発走時刻変更（TC）、コース変更（CC）。発表日時を持つものがある。
- オッズ：現行オッズは全式別。履歴時系列は単勝・複勝・枠連・馬連に限定され、発表時刻を持つ。

公式の配信予定では、概ね日曜夕方に特別登録、木曜 16:30 頃に馬番なし出馬表、木曜 20:00 頃に更新、開催前日 12:00 頃に馬番確定出馬表、馬体重は発走約 1 時間前、確定成績は月曜 14:00 頃に提供される。速報・現行オッズは開催中更新される。時系列オッズは 5～10 分間隔とされる。

時系列オッズのオンライン保持は仕様上 **1 年保証**である。保証期間を超えて取得できることを、再現可能な履歴要件として仮定してはならない。

#### 不確実性

- 項目ごとに開始時期・欠損率が異なる。1986 年以降という表現は、全フィールドが同じ品質で揃うことを意味しない。
- 初回セットアップで得られる古いデータは、当時配信された原版ではなく、後日訂正を反映した最新既知版である可能性がある。古い訂正の発行時刻を完全には復元できない。
- 時系列オッズを 1 年より古く利用できる場合があっても、公式保証外である。

### 4.2 取得方式と運用制約

#### 事実

- 開発ソフトは JV-Link ActiveX/COM を呼び出し、認証・ダウンロード・キャッシュを JV-Link に任せる。
- SDK 開発ガイドは、受信した JVData をソフト側データベースへ登録し、予想・表示ではローカル DB を参照する構成を示す。
- SDK 自体は提供されるが、実データ取得には Data Lab. の契約キーが必要である。
- Data Lab. は Windows 10/11 日本語版の PC 向けであり、2 台まで利用できる。通常料金は月額 2,090 円（税込）。
- 現行オッズを更新間隔より短く反復要求しても新しい値は得られず、負荷の大きい取得を避ける必要がある。

#### 解釈・示唆

- 将来の収集基盤は Windows 上の正規 JV-Link 取込プロセスと、モデル学習環境を分離できる構成が望ましい。ただし、本調査では実装しない。
- JV-Link のローカルキャッシュだけを履歴台帳とせず、将来は原文レコード、取得時刻、発表時刻、データ種別、JVData バージョンを別途保存する必要がある。
- サーバーへ直アクセスする独自クローラ、JV-Link の解析・迂回、過剰ポーリングは行わない。

### 4.3 規約と研究利用

#### 事実

- JRA-VAN 利用規約第 7 条は、利用者本人の個人的かつ私的な利用の範囲を超えるサービス情報の利用・公開、第三者利用を、会社が認めた場合を除き禁じる。
- 同利用規約はサービスの利用地域を日本国内に限定する。取得hostやcloud保存・処理先の所在は、公開・第三者提供とは別の確認事項になる。
- 同第 9 条は、Data Lab. サーバーへのアクセスを JV-Link に限定し、JV-Link のリバースエンジニアリング等を禁じる。
- 2026-08-07 の JRA-VAN 公式サポート回答は、「個人利用」「ローカルの研究環境」「正規の SDK/JV-Link」「生データを AI に送らない」という質問条件について規約上問題ないとした。同時に AI エージェントによる大量・想定外・規約外アクセスへの注意を求めた。
- 2026-07-06 の公式回答は、通常の Data Lab. 契約で取得したデータをアプリやサービスとしてエンドユーザーへ提供する商用利用は不可で、JRADB の法人向け商用契約が必要とした。料金は公開せず問い合わせ制である。

#### 解釈・示唆

- 現段階の「利用者個人によるローカルな私的研究」は、確認済み条件に合わせれば採用可能性が高い。
- MVPの取得hostとraw data保存・処理境界は日本国内に置く。海外regionへの転送は許諾済みとみなさず、必要なら具体的構成を書面照会する。
- 次は回答範囲外であり、許諾済みとはみなさない：複数人での生データ共有、外部 SaaS/AI への投入、公開リポジトリへのデータ掲載、学習データや予測 API の第三者提供、法人利用、有償販売。
- コード、スキーマ、集計ロジックの公開可否と、生データ・復元可能な派生物の公開可否は分けて判断する。集計済み特徴や学習済みモデルが第三者提供に当たるかは、用途が具体化した時点で書面確認する。

## 5. JRA 公式 Web/JRADB

### 事実

- JRA は 1986 年以降のレース成績を掲載する。2000 年より前は一部情報が掲載されない場合がある。成績 PDF は 2002 年以降である。
- 成績ページでは、開催条件、天候・馬場、着順、枠・馬番、馬名、性齢、斤量、騎手、タイム、着差、通過順、推定上がり、馬体重、調教師、人気、レース注記等を確認できる。
- 馬情報ページでは、馬プロフィール、血統、馬主、調教師、生産者、競走成績等を確認できる。
- JRA の「ご利用に際して」は掲載内容の著作権等を明示する。一方、本調査で JRA Web の公開一括取得 API、自動取得頻度、恒久保存、加工 ML 利用を明示的に許可する公式資料は確認できなかった。

### 解釈・示唆

- 公式一次情報の照合、例外ケース確認、仕様理解には使える。
- 画面の可視性を根拠にスクレイピングを許諾済みとは扱わない。主取得を JRA-VAN に置けば、JRA Web への自動負荷と利用条件の不明確さを避けられる。
- Web/PDF は現在の表示版であり、任意の予測時点における版やオッズ時系列の再現源ではない。

## 6. netkeiba

### 事実

- 競馬データベースは、1956 年以降にデビューした競走馬と、レース、騎手、調教師、馬主、生産者等を検索できると案内する。情報提供元として JRA、地方競馬全国協会、JBIS、JBBA 等を掲げる。
- 有料プランには、過去 5 走、調教タイム、厩舎コメント、タイム指数、トラック指数等が含まれる。料金は Web とアプリで表示が異なり、Web の確認ページでは Premium 640 円/月、Super Premium 1,390 円/月または年額 13,900 円、別アプリページでは 600/1,200 円等だった。
- 更新時刻ヘルプは、特別登録、想定、出馬表、枠順、オッズ、調教、コメント、レース結果、独自指数ごとの概略時刻を案内する。
- 利用規約第 14 条は、運営者の承認なく、著作権法上の私的利用を超えて取得データを利用・公開することを制限し、事実データも著作物とみなすと定める。第 15 条は商業目的の利用とその準備を、第 16 条は不正アクセスやサービス妨害等を禁止する。
- 公式の公開一括 API、スクレイピング許諾、履歴スナップショット保証、オッズ時系列ダウンロード仕様は確認できなかった。

### 不確実性と提案

- 個人のローカル ML が「私的利用」に含まれるか、自動取得と大量保存が認められるかは明示されていない。
- 価格・提供項目は購入チャネルにより異なる。採用検討時は契約するチャネルの最新表示を確認する。
- したがって、Web スクレイピングや認証画面の自動取得は採用しない。独自調教評価等が不可欠になった場合に、運営会社へ用途・量・保存・派生物を具体的に書面照会する。

## 7. JBIS-Search

### 事実

- JBIS は JRA、NAR、日本軽種馬協会、日本軽種馬登録協会等を元に、血統、生産、セリ、競走成績を提供する。
- 原則として競走馬情報は 1984 年生以降で、1972～1983 年生は一部項目のみ、それ以前は不完全である。JRA のレース成績は 1986 年以降である。
- 中央競馬の出馬表は木曜 16:30 頃および金・土曜 11:00 頃、結果は月曜 12:00 以降に更新すると案内する。
- 馬詳細にはプロフィール、5 代血統、父系・母系、全競走成績、産駒・種牡馬成績、母父成績、市場取引等がある。
- 利用規約第 8 条は、情報を個人的用途等に限定し、原則「そのまま」の形で利用すること、私的利用等を超える複製・改変・第三者利用、営利目的等を制限する。第 10 条は協会が提供するインターフェース以外からのアクセス等を制限する。
- 一括 API、公式バルクダウンロード、PIT スナップショット、オッズ履歴は確認できなかった。

### 解釈・示唆

- とりわけ血統・セリ情報の公式性は高いが、「加工して特徴量化する大量 ML 利用」が規約上明確に許諾されたとはいえない。
- MVP の主取得源にはせず、JRA-VAN の血統・セリ情報との目視照合に使う。追加採用時は、取得方法、ローカル保存、加工、学習、モデル出力の扱いを事前に照会する。

## 8. JRDB

### 事実

- JRDB はレース、馬、厩舎、騎手、成績に加え、独自指数、調教分析、パドック、馬具・脚元、直前情報等の定型テキストデータを配信する。
- 曜日・時刻ごとの配信が定義されている。仕様書は、週次マスタについて「土曜成績を日曜マスタ値に含めない」例を明記しており、同じ週の後半でも集計時点が一定とは限らない。
- 料金ページでは基本コースを初月・2 か月目 3,000 円、その後 2,380 円/月、上位コースを 3,500 円、その後 2,880 円/月等と案内する。
- 会員規約は、契約者個人の競馬予想用途に限定し、第三者提供、私的目的を超える複写・改変、商用販売、法人利用等を制限する。
- 現行公式ページから、全項目の履歴開始年、過去版の保持、訂正時刻、ML 学習・派生モデルの許諾は確定できなかった。

### 解釈・示唆

- JRA-VAN にない主観情報や加工済み情報の増分価値を検証できる候補だが、MVP に混ぜると、情報源の効果、独自指数の定義、オッズ由来成分、公開時刻が曖昧になる。
- 後続の独立した特徴群アブレーションとして検討する。契約前にサンプルで期間、欠損、訂正、公開時刻を監査し、ML・保存・共同利用の許諾を確認する。

## 9. NAR 公式データダウンロード（補助候補）

### 事実

- 地方競馬情報サイトは公式 ZIP/CSV ダウンロードを提供する。日次ファイルは概ね 2 分間隔で更新され、当日情報と中間オッズを含む。月次ファイルは日々 02:00 頃更新され、結果・確定オッズを含む。
- レース情報は 1998-01 以降、オッズは 2026-03 以降と案内される。古い期間には欠損がありうる。
- 規約はサイト情報の無断転載・複製等を制限し、異常アクセスを遮断しうるとする。公式 DL 機能がある一方、恒久保存・加工 ML 利用・派生物共有の範囲は明示されていない。

### 解釈・示唆

- JRA 出走馬の地方成績を補う可能性はあるが、JRA-VAN 内の JRA 関連地方歴と比較し、増分と ID 対応を別途検証する。
- 公式ダウンロードだから無制限利用可能とは解釈しない。用途を伝えた書面確認後の追加候補とする。

## 10. 推奨するデータ調達方針

### 推奨

1. 個人研究の MVP は JRA-VAN Data Lab./JV-Link を主ソースとする。
2. JRA Web、netkeiba、JBIS は自動収集源にせず、公式ページ・表示差異の目視照合に限定する。
3. JRDB は、JRA-VAN ベースライン確立後に、独自情報の増分を一仮説ずつ検証する候補とする。
4. JRA-VAN 生データを外部生成 AI、公開リポジトリ、共同共有ストレージへ送らない。取得・保存・処理hostは日本国内とし、コードとデータを明確に分離する。
5. 利用主体・用途が変わる前に、JRA-VAN/JRADB へ次を明記して書面照会する：個人/法人、ローカル/クラウド、取得頻度、保持期間、共同利用者、特徴量・予測・学習済みモデルの公開、有償/無償。
6. 利用規約と公式サポート回答は、契約時点の版、取得日、問い合わせ記録を保存する。

## 11. 未解決事項

- JRA-VAN の学習済みモデル、集計済み特徴、個々の予測値を第三者に提供する場合の線引き。
- 個人所有クラウドへの暗号化バックアップや、外部計算環境への一時転送が「個人的・私的利用」の範囲に入るか。
- JV-Link の項目別実データ欠損率、古いレコードの訂正履歴、時系列オッズの実取得可能最古日。
- JRDB の全項目についての履歴開始年、PIT 版の保存、独自指数のオッズ依存、ML 利用許諾。
- netkeiba/JBIS/NAR の個人ローカル ML、自動取得、長期保存、派生物利用についての明示的許諾。
- JRA-VAN が収録しない地方・海外歴を追加する場合の公式 ID 対応と利用条件。
