# 利用可能な特徴量の調査

## 1. 目的と前提

本書は、初期の JRA 中央競馬モデルで候補となる情報を、JRA-VAN Data Lab./JV-Link を主ソースとして整理する。調査日は **2026-08-30** である。取得できる生項目と、そこから構築する特徴量を分け、予測時点より後の情報を使わないことを最優先する。

本書の「利用可」は、データとして存在するという意味であり、すべてを初期モデルへ投入するという意味ではない。ID は結合キーに限定し、単勝オッズ等の市場情報は合意済み方針どおり一次予測モデルから除外する。

### 調査した質問

- 初期モデル候補となる生項目と、そこから作る過去のみの集計特徴は何か。
- 各項目のソース、履歴期間、欠損、予測時点での可用性、リーケージ危険、期待有用性は何か。
- 前日予測と当日予測で使える情報はどう異なるか。
- 馬、騎手、調教師、血統、相手関係を、生 ID の記憶ではなく PIT 集計へどう変換するか。
- 一次予測モデル、市場比較、ベット判断、結果ラベルをどう分離するか。

## 2. 情報層の整理

```text
source record
  ├─ race definition / entries
  ├─ entity master and point-in-time snapshot
  ├─ pre-race event updates
  ├─ training and historical performance
  ├─ market odds
  └─ post-race result and payout
           ↓ point-in-time filtering
feature-ready event history
           ↓ only past information
horse / jockey / trainer / opponent aggregates
           ↓ race-level join at prediction_time
model matrix + market-side table + labels
```

ソースレコード、特徴量、オッズ、ラベルを同じ無区分テーブルに置くと誤結合しやすい。この四者は論理的にも物理的にも分ける。

### 3.4 調教

#### 事実

- JRA-VAN は坂路調教を 2003 年から収録する。
- ウッドチップ調教は美浦 2021-07-27、栗東 2021-12-07 からである。
- 調教レコードには調教日、時刻/ラップ等がある。提供は平日に随時行われる。

| 候補特徴 | 構成例 | 有用性仮説 | 注意点 |
|---|---|---|---|
| 最新時計 | 最新 4F/3F/1F、区間加速 | 中～高 | コース別・馬場別に尺度が違う |
| 調教量 | 過去 7/14/28 日の本数、総負荷 | 中 | 未収録調教をゼロとしない |
| 追い切り間隔 | 最終調教から発走までの日数 | 中 | 公開時刻が cutoff 後なら不可 |
| 変化 | 同馬平均との差、直近傾向 | 中 | 2003/2021 の構造欠損を明示 |
| 厩舎内相対 | 同日同コースの厩舎平均との差 | 中 | 同日後刻の情報を混ぜない |

#### 不確実性

- 坂路・ウッド以外の全調教を網羅するわけではなく、調教強度・意図を時計だけから一意に解釈できない。
- 古い期間と東西でカバレッジが大きく異なるため、長期全期間へ単一の欠損処理を適用すべきでない。

### 3.6 オッズ・投票・払戻

#### 事実

- 現行オッズは全式別が対象である。
- 時系列オッズは単勝・複勝・枠連・馬連に限られ、発表時刻を持ち、概ね 5～10 分間隔である。
- 時系列の取得保証は 1 年である。
- 確定オッズ、人気、払戻、確定投票数は結果側情報である。

#### プロジェクト上の分離

| 用途 | 使用可能な値 | 禁止/要注意 |
|---|---|---|
| 一次 `P(win)` / ranking モデル | 原則オッズなし | 人気、確定オッズ、投票数、オッズ由来指数を混ぜない |
| 市場比較 | cutoff 以前の最新単勝オッズ、スナップショット時刻、経過秒 | cutoff 後のオッズ、最終オッズへの置換 |
| ベット判定 | 同じ cutoff の予測確率と観測可能オッズ | 予測とオッズの時点不一致 |
| 診断 | 確定オッズによる事後市場比較を別枠表示可 | 現実的バックテストと呼ばない |
| ラベル/損益 | 確定着順、公式払戻 | 学習入力へ混入させない |

## 4. 派生特徴量カタログ

### 4.1 馬の履歴

任意の対象レースについて、`past_race.start_time < prediction_time` を満たす履歴だけを使う。最近数走だけへ任意に切らず、全履歴を保存した上で複数窓・条件別・減衰集計を構成する。

| 特徴群 | 例 | 推奨窓/条件 | 期待 | リスク |
|---|---|---|---:|---|
| 出走量 | 通算、365/180/90/30 日出走数 | 暦日窓 | 中 | 若馬の少数標本 |
| 休養・疲労 | 前走からの日数、短間隔連戦、直近総距離 | 7/14/28/60 日 | 高 | 開催中止・取消は出走扱いしない |
| 着順成績 | 勝率、連対/複勝率、平均百分位順位 | 通算+365/180/90 日 | 高 | 頭数調整、少数標本縮約 |
| 速度・着差 | 条件調整時計、勝馬差、上がり差 | surface×distance band×course | 高 | 時計の年代・馬場差、異常値 |
| 展開 | 通過順位変化、先行度、上がり順位 | 直近+条件別 | 中～高 | コーナー欠損をゼロにしない |
| 適性 | 芝/ダ、距離帯、場、回り、馬場、季節 | 複数条件 | 高 | 高次組合せの疎性 |
| クラス | 過去クラス、昇降級、相対パフォーマンス | 制度版別 | 高 | 将来のクラス/獲得賞金を参照しない |
| 斤量 | 過去斤量、今回との差、体重比 | 条件別 | 中 | 今回馬体重未発表時の扱い |
| コンディション | 馬体重水準/変化、長期トレンド | 直近+EWMA | 中～高 | 当日値は時点依存 |
| 安定性 | 成績/速度の分散、悪化・改善傾向 | 5走、180/365 日 | 中 | 3走未満等の信頼度 |

集計値には、値だけでなく観測数、最終観測からの経過日数、欠損理由、分散または不確実性を添える。

### 4.2 騎手・調教師・組合せ

| 特徴群 | 例 | 期待 | リスクと対策 |
|---|---|---:|---|
| 騎手過去成績 | 勝率、上位率、平均相対順位 | 高 | 現在マスタの通算値を使わず過去結果から再計算 |
| 騎手条件適性 | 場、芝ダ、距離帯、クラス別 | 中～高 | ベイズ/経験的縮約、観測数併記 |
| 調教師過去成績 | 直近調子、年間/条件別成績 | 高 | 年末確定値等の未来集計を使わない |
| 馬×騎手 | 騎乗回数、過去相対成績 | 中 | ペア ID の記憶を避け集計へ |
| 騎手×調教師 | 起用回数、過去成績 | 中 | 同上、低頻度カテゴリ縮約 |
| 乗替り | 継続、初騎乗、変更、前騎手との差 | 中～高 | 発表時点の版を使用 |

ID は時点正しい結合に必要だが、初期モデルには生 ID を投入しない。登録名の表記揺れではなく公式 ID で履歴を結合し、結果を過去統計へ変換する。

### 4.3 フィールド・相手関係

| 特徴群 | 例 | 期待 | リーク防止 |
|---|---|---:|---|
| 当該レース内相対 | 各特徴の field rank、平均との差、z-score | 高 | 全馬で同一 cutoff の特徴を使う |
| フィールド強度 | 出走馬の事前 rating の平均/上位/分散 | 高 | rating は各馬の cutoff 前履歴のみ |
| 過去相手強度 | 過去レース時点の相手事前 rating | 高 | 相手のその後の成績を逆流させない |
| 再戦 | 過去対戦と当時差 | 中 | 対戦後の情報は次回時点なら利用可 |
| ペース構成 | 事前脚質の先行馬数、分布 | 中～高 | 対象レース通過順位を使わない |
| 枠×頭数 | 枠位置百分位、内外、頭数との相互作用 | 中 | 取消後に再計算する定義を固定 |

過去レース価値の計算は、対象過去レースの時点で凍結した相手強度を基本とする。後から強豪と判明したことを過去評価へ反映する retrospective 指標を作る場合は、研究用の別特徴群として明示し、本番相当評価から除外する。

| 特徴群 | 例 | 期待 | 注意点 |
|---|---|---:|---|

| 生産者過去集計 | 対象時点以前の産駒成績 | 低～中 | 規模 proxy と ID 記憶を分ける |

| 特徴群 | 前日モデル | 当日モデル | 注意点 |
|---|---:|---:|---|
| 当日天候・馬場 | 原則不可 | cutoff 前発表値 | 結果レコードの最終状態で置換しない |

## 5. ラベル候補

| タスク | ラベル | 使用時点 | 備考 |
|---|---|---|---|
| binary | `finish_position == 1` | 確定後のみ | 同着の公式扱いを仕様化 |
| ranking | 確定着順または relevance 変換 | 確定後のみ | 中止・失格・降着を明示処理 |
| probability diagnostics | 勝敗 | 確定後のみ | race group 単位の整合性確認 |
| betting P/L | 勝敗 + 公式払戻 | 確定後のみ | オッズ入力ではなく評価結果 |

取消・除外は出走行ではなく、予測対象集合から外す。競走中止、失格、降着、同着は、JRA の確定結果に沿った共通ルールを別仕様で定義し、モデルごとに変えない。

## 6. 調査結果とプロジェクトへの示唆

### 確認できた事実

- JRA-VAN だけで、初期構造化モデルに必要なレース条件、過去成績、馬・関係者、血統、調教、当日変更、オッズ、結果・払戻を概ね取得できる。
- ただし開始年は一様でなく、1994-07 前の一部項目、詳細成績、2003 年開始の坂路、2021 年開始のウッド等に時代別の構造欠損がある。
- 馬体重、当日天候・馬場、変更、オッズは前日には未確定で、発表時刻を伴う race-day 情報である。
- 時系列オッズは式別・保持期間が限定され、確定オッズ・人気・払戻は事後情報である。

### 解釈・示唆

- 同じモデル名でも、前日版と当日版は入力可能情報が異なる別データプロダクトとして管理すべきである。
- 最長履歴を一律に使うより、特徴群ごとの coverage era、欠損率、PIT 品質を監査し、共通期間と長期疎データ期間の感度を比較すべきである。
- 一次モデルの no-odds 方針はデータ層で強制し、後段の market snapshot と結果ラベルを別テーブルにすることが、実験上の解釈性と漏洩防止の双方に有効である。
- ID の直接投入を避けても、公式 ID は履歴結合に不可欠である。対象時点以前の縮約済み統計へ変換する。

## 7. 初期特徴セットの提案

### 推奨

初期 no-odds LightGBM 共通パイプラインは、次の分離可能な特徴群から始める。

1. `race_context`: 場、芝ダ、距離、コース、クラス、条件、頭数、枠・馬番。
2. `horse_history_basic`: 出走間隔、複数窓の着順百分位・着差・速度・上がり・通過位置・馬体重。
3. `horse_conditioned_history`: 芝ダ、距離帯、場、馬場、クラス別の過去集計。
4. `connections_history`: 騎手、調教師、馬×騎手の過去のみの縮約集計。
5. `field_relative`: 当該レース内順位、平均との差、過去時点 rating によるフィールド強度。
6. `pedigree_history`: 父・母父・牝系の対象時点以前の産駒集計。
7. `training`: まず坂路、後にウッドを別アブレーション。
8. `race_day_state`: 馬体重、天候馬場、変更速報。前日版とは別データセット/実験。
9. `market_snapshot`: 一次モデルには結合せず、ベット判断・市場比較専用。

各群は独立に ON/OFF でき、1 実験 1 仮説で追加する。古い期間に存在しない項目を単純なゼロにせず、`value`, `observed`, `coverage_era`, `age_seconds/days` を持たせる。

## 8. 不確実性と追加調査

- 実データを契約取得していないため、項目別欠損率、コード値の長期変遷、訂正頻度は未測定である。
- 1994-07 前、コーナー・上がり等の古い期間、地方/海外歴、調教には構造欠損がある。学習開始年は単なる最大期間ではなく、特徴群別カバレッジ監査後に決める。
- JRA-VAN の木曜スナップショットは 2004 年以降であり、古い時代の厳密な関係者・馬属性版は保証されない。
- クラス制度、年齢表記、コース改修、計時・発表制度の変化をコード表と開催日で版管理する必要がある。
- オッズ時系列は 1 年保証のため、長期間の現実的なベット時点評価を当然には作れない。収集開始後に利用可能期間を実測する。
